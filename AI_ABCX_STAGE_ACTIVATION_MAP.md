# AI-ABCX Stage Activation Map

This document defines the working stage-activation model for the `AI-ABCX` company structure.

It is intended to guide:

- President dashboard behavior
- executive and director visibility
- stage-based system messaging
- future landing-page and product-positioning language

---

## Core Rule

The full `A/B/C` structure should be visible from `Stage A`.

But visibility is not the same as equal activation.

Each role should be shown according to:

- whether it is active now
- whether it is limited-active
- whether it is structurally present but future-stage
- what real operating truth exists to support it

## Status Definitions

| Status | Meaning |
|---|---|
| Active | Fully selectable, rich signals, real recommendations, strong dashboard presence |
| Lean Active | Active, but narrower scope and fewer inputs than later stages |
| Limited Active | Selectable and useful, but with reduced depth and fewer management elements |
| Visible / Limited | Shown as part of the structure, with partial signals or stage markers |
| Visible / Future | Visible as part of the company structure, but not yet functionally active |
| Advanced | Same role continues, but with deeper automation, governance, forecasting, and intelligence |

---

## Dashboard Rule

For the President dashboard:

- `Stage A` should show the full `A/B/C` structure
- only roles with believable operating truth should feel strongly active
- future roles should remain visible so the owner sees the full company model from day one

This keeps the dashboard aligned with the product philosophy:

`AI-ABCX brings corporate structure to service businesses.`

`You lead as President.`
