# AI-ABCX Director A/B/C Normalization Index

This document is the master index for all normalized `A / B / C` launch-definition files.

Its purpose is to make the current planning set easier to use for:

- pricing architecture
- dependency mapping
- launch packaging
- diagnostic recommendation logic

This index does not replace the detailed individual files.

It exists to show:

- which directors are already normalized
- where each director sits in the executive structure
- the final plain-language lock for each director

## Core Rule

Every normalized launch-definition file follows the same final logic:

- `A` = visible control / truth / discipline / routing at a basic operating level
- `B` = connected workflow and stronger operational coordination
- `C` = advanced orchestration and higher automation depth

The exact wording changes by director, but the structure remains the same.
