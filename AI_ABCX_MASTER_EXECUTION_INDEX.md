## 7. What Has Already Been Decided

The following product decisions are already materially established:

### Product model

- AI-ABCX is a President-led corporate operating system
- executives are core structure
- directors are the priced functional layer

### Pricing model

- public pricing should be dollar-based
- hidden-cost / AI-credit confusion should be avoided
- Website Director has hosted and external-site connector paths
- Call Handling Director includes director charge plus usage logic

### Diagnostic model

- Step 1 is a real business diagnostic
- the system must recommend custom configuration
- the recommendation should include:
  - intent-fit
  - improved
  - advanced
- the output should explain why the system was configured that way

### Launch sequencing model

- Wave 1 first
- then Wave 2
- then Wave 3
- then Wave 4

### Launch philosophy

- build strongest entry offers first
- then complete the operational chain
- then complete growth
- then complete corporate depth

## 9. Recommended Working Method

When moving from planning into execution, use this exact order:

1. open the relevant wave implementation plan
2. open the per-director build checklist
3. confirm current repo evidence in the implementation inventory
4. build the product surface
5. lock A/B/C logic
6. lock dependency rules
7. lock pricing logic
8. define tests
9. mark the director state forward in the status matrix

This prevents design work, logic work, and pricing work from drifting apart.
