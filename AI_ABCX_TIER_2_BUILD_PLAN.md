# AI-ABCX Tier 2 Build Plan

This document turns the launch checklist into a concrete second-wave build plan for the connected revenue and operations directors.

Its purpose is to answer one practical question:

`What exactly must be built after Tier 1 so AI-ABCX becomes a connected operating system instead of only three strong entry modules?`

This plan is intentionally limited to the Tier 2 directors:

- Follow-Up Director
- Scheduling Director
- Dispatch Director
- Sales Director
- Reactivation Director
- Lead Generation Director
- Advertising Director
- SEO Director

These are the next directors because they stabilize flow after entry, convert demand into revenue, and connect acquisition, estimating, operations, and growth inside one visible system.

---

## 1. Tier 2 Rule

Tier 2 should be treated as the connectivity layer.

Tier 1 creates strong commercial entry:

- estimate-led
- phone-led
- website-led

Tier 2 turns those entries into:

- tracked follow-up
- booked work
- field movement
- closed revenue
- reactivated revenue
- new lead flow
- paid demand
- organic demand

Tier 2 should not be treated as complete until each director has:

- usable product surfaces
- locked naming
- valid A / B / C definitions
- valid dependency logic
- President dashboard visibility
- guided activation logic
- isolated tests
- bundle tests

---

## 2. Tier 2 Sequence

Recommended build order:

1. Follow-Up Director
2. Scheduling Director
3. Dispatch Director
4. Sales Director
5. Reactivation Director
6. Lead Generation Director
7. Advertising Director
8. SEO Director

Why this order:

- Follow-Up closes the leaks between inquiry, estimate, sales, service, and President attention.
- Scheduling and Dispatch are the next operations stabilizers once demand begins moving.
- Sales Director becomes much stronger once estimate, follow-up, and appointment visibility are real.
- Reactivation extends revenue from the existing database after base sales logic is stable.
- Lead Generation, Advertising, and SEO should be built as one acquisition cluster after the conversion path is already usable.

---

## 3. Shared Tier 2 Requirements

All Tier 2 directors must follow the same system discipline.

### Shared requirement 1: Canonical naming

- one public-facing director name
- one internal config name
- one dashboard name
- one registry name

### Shared requirement 2: A / B / C architecture

Each Tier 2 director must have:

- Level A
- Level B
- Level C
- upgrade triggers
- downgrade logic if applicable

### Shared requirement 3: Dependency logic

Each Tier 2 director must clearly state:

- what it can do independently
- what it can only do in combination
- what directors feed into it
- what directors it feeds outward into

### Shared requirement 4: President visibility

Each Tier 2 director must show up in the President structure as:

- visible lane
- visible outcomes
- visible unresolved states
- visible next recommended action

### Shared requirement 5: Guided activation logic

Step 1 must eventually qualify:

- whether the company needs the director
- what level the company is ready for
- what business problem the director solves

### Shared requirement 6: Testing discipline

Each Tier 2 director must have:

- isolated tests
- bundle tests
- dashboard verification
- upgrade path testing

## 12. Tier 2 Bundle Tests

These tests must exist before Tier 2 is considered complete as a group.

### Bundle test 1: Estimate to close path

- Estimator Director creates demand record
- Follow-Up Director holds unresolved next step
- Sales Director prioritizes and closes

### Bundle test 2: Call to schedule to dispatch path

- Call Handling Director captures demand
- Scheduling Director creates appointment state
- Dispatch Director controls field movement

### Bundle test 3: Website to lead to sales path

- Website Director captures inquiry
- Lead Generation Director tags source
- Sales Director and Follow-Up Director carry conversion

### Bundle test 4: Old database recovery path

- Reactivation Director opens old record segment
- Follow-Up Director tracks next step
- Sales Director closes recovered opportunity

### Bundle test 5: Paid and organic acquisition path

- Advertising Director or SEO Director produces lead visibility
- Lead Generation Director tracks source quality
- Sales Director receives opportunity quality signal
