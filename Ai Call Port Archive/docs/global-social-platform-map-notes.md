# Global Social Platform Map

This is a working expansion list for AI Call Port's global organic presence strategy.

It is organized by:
- continent
- country or region
- platform
- platform type
- whether we can create an owned brand presence
- whether the platform is useful for group or community distribution
- whether the platform is useful for long-form article distribution
- language localization value
- priority tier

## Important

This is not literally every platform in the world.

That would be unstable and never truly complete because:
- platforms launch and die constantly
- local communities shift quickly
- some countries use forums, channels, or messaging ecosystems more than classic social platforms
- platform relevance changes by language, industry, and regulation

So this file should be treated as:

`Version 1 of the master platform database`

## Priority Logic

- `Tier 1`
  Highest-priority platforms for AI Call Port brand presence, article distribution, multilingual scaling, or community reach.

- `Tier 2`
  Strong secondary platforms that are worth building once Tier 1 coverage is organized.

- `Tier 3`
  Test channels, niche local platforms, or lower-priority networks that may still matter in specific regions.
