# AI-ABCX Call Agent And Voice Structure

This document defines how `Call Handling` should be structured commercially and functionally inside AI-ABCX.

It separates:

- `Call Agent level` = automation and handling sophistication
- `Voice tier` = voice quality and customer experience quality

It also includes:

- language pack logic
- per-minute usage logic
- administrative charge logic

---

## 1. Core Rule

Call Handling should not be sold as one flat undifferentiated product.

It should be structured as:

1. `Call Agent level`
2. `Voice tier`
3. `Language packs`
4. `Usage charge`
5. `Administrative charge`

This creates a flexible but understandable commercial model.

---

## 2. Main Offer Structure

The call-handling offer should be described like this:

`Call Agent [A/B/C/X] + Voice [A/B/C/X] + optional language packs`

Examples:

- `Call Agent A + Voice A`
- `Call Agent A + Voice C`
- `Call Agent B + Voice B`
- `Call Agent C + Voice X + Spanish Pack`

This keeps:

- automation level clear
- voice quality clear
- multilingual add-ons clear

---

## 3. Call Agent Automation Ladder

The Call Agent level controls how sophisticated the handling and workflow connection are.

### Call Agent A

Foundational corporate intake layer.

Should include:

- answer inbound calls
- capture caller identity
- capture reason for call
- basic urgency detection
- basic caller qualification
- basic lead qualification
- create CRM record
- transcript and recording linkage

This is basic but real operating value.

### Call Agent B

Connected operational automation layer.

Should include everything in A, plus:

- stronger workflow routing
- deeper scheduling/dispatcher connection
- stronger qualification depth
- stronger after-hours logic
- better next-step movement into the system

### Call Agent C

Advanced call-management automation layer.

Should include everything in B, plus:

- advanced call logic
- stronger exception handling
- deeper call quality and management visibility
- stronger recommendation support
- broader operating intelligence

### Call Agent X

Full intelligent call orchestration layer.

Should include everything in C, plus:

- fullest automation depth
- strongest orchestration across the corporate system
- highest intelligence maturity in call behavior and workflow linkage

---

## 4. Voice Quality Ladder

The voice tier controls how premium and natural the agent sounds.

This is separate from how sophisticated the logic is.

### Voice A

- clear
- functional
- acceptable base customer experience
- lower-cost voice tier

### Voice B

- more natural
- better pacing and tone
- stronger customer comfort
- improved overall sound quality

### Voice C

- premium naturalness
- more polished brand impression
- stronger conversational quality
- more impressive live experience

### Voice X

- highest-end voice experience
- most polished and premium sound
- strongest “wow” factor
- best brand-representation tier

---

## 5. Language Pack Rule

English should be included by default.

Additional languages should be sold as language packs.

Examples:

- English included
- Spanish Pack
- Russian Pack
- future additional language packs

### Important separation

At first, language packs should primarily mean:

- call agent language support

They should not automatically imply:

- full internal dashboard localization
- full platform translation

That can be separate later if needed.

---

## 6. Usage Rule

Call Handling should include:

- fixed administrative/platform charge
- per-minute usage charge

This is the correct pricing model because:

- AI call handling has real variable cost
- usage should scale fairly with actual call volume
- fixed module pricing alone is not enough

---

## 7. Administrative Charge Rule

The administrative charge should cover:

- module access
- configuration
- routing logic
- CRM/dashboard connection
- transcript/record handling
- management of the active agent setup

This charge can increase by Call Agent level because higher levels deliver more sophistication.

---

## 8. Example Commercial Logic

The final offer for Call Handling should be built from:

### Base structure

- `Call Agent level fee`
- `Voice tier selection`
- `language pack charges`
- `per-minute usage`
- `administrative charge`

### Example pricing logic shape

- `Call Agent A` = lower fixed sophistication fee
- `Call Agent B` = higher fixed sophistication fee
- `Call Agent C` = premium fixed sophistication fee
- `Voice A` = included or lowest-cost voice tier
- `Voice X` = highest premium voice tier
- `English` = included
- additional languages = add-on packs
- usage = billed per minute

---

## 9. Product Logic Benefit

This structure is strong because it allows:

- low-cost entry
- premium upsell
- quality-based differentiation
- multilingual upsell
- fair usage pricing
- clear ABCX alignment

It also lets a customer choose:

- better voice first
- better automation first
- both later

That is flexible without becoming confusing.

---

## 10. Examples

Valid example offers:

- `Call Agent A + Voice A`
- `Call Agent A + Voice B`
- `Call Agent A + Voice X`
- `Call Agent B + Voice B`
- `Call Agent B + Voice C + Spanish Pack`
- `Call Agent C + Voice X + 2 language packs`

---

## 11. Upgrade Paths

Customers should be able to upgrade in multiple ways.

### Agent upgrade

- `Call Agent A` -> `Call Agent B`
- `Call Agent B` -> `Call Agent C`
- `Call Agent C` -> `Call Agent X`

### Voice upgrade

- `Voice A` -> `Voice B`
- `Voice B` -> `Voice C`
- `Voice C` -> `Voice X`

### Language expansion

- add one or more language packs later

This creates a layered expansion path without forcing one giant jump.

---

## 12. Relationship To Stage Releases

The stage-release rule should still apply:

- `Stage A` launch makes `Call Agent A` available
- `Stage B` release unlocks `Call Agent B`
- `Stage C` release unlocks `Call Agent C`
- `Call Agent X` remains the later highest intelligent level

Voice tiers can either:

- all be available from the start
or
- be limited by commercial strategy

My recommendation:

- keep voice tiers commercially flexible
- keep agent automation levels tied to stage release logic

---

## 13. Main Definition

AI-ABCX Call Handling should be defined as:

`Call Agent level + Voice tier + language packs + usage pricing + administrative charge`

This is the governing structure for the Call Handling commercial model.

---

## 14. Next Decisions Needed

To finalize the offer, the next decisions should define:

1. what `Call Agent A/B/C/X` exactly includes in product behavior
2. what `Voice A/B/C/X` exactly means commercially
3. whether all voice tiers are available from Stage A
4. whether Voice A is included or separately priced
5. which language packs are first available
6. the actual administrative and per-minute pricing logic
